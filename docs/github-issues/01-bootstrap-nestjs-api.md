# Bootstrap NestJS API

## Contexto

O backend `dogs-api` precisa nascer como um projeto NestJS separado do frontend `react-dogs`.

## Objetivo

Criar o scaffold inicial do projeto com Node.js, TypeScript, NestJS e Yarn.

## Escopo

- Inicializar projeto NestJS.
- Configurar `src/main.ts` e `src/app.module.ts`.
- Criar estrutura inicial de pastas.
- Garantir que o projeto rode localmente.
- Atualizar README com comandos básicos.

## Fora De Escopo

- Prisma.
- Banco de dados.
- Auth.
- Swagger.
- Deploy.

## Critérios De Aceite

- `yarn dev` sobe a aplicação.
- `yarn build` gera build sem erro.
- Estrutura inicial segue `docs/INITIAL_SCAFFOLD_PLAN.md`.
- README descreve setup local mínimo.
