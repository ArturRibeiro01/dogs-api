# Criar Documentação Base E Notas Do Codex

## Contexto

O projeto precisa ser fácil de retomar por humanos e pelo Codex.

## Objetivo

Criar a documentação base do backend e `.codex/project.md`.

## Escopo

- Criar ou revisar `docs/DEVELOPMENT.md`.
- Criar ou revisar `docs/ARCHITECTURE.md`.
- Criar ou revisar `docs/ENVIRONMENTS.md`.
- Criar ou revisar `docs/SECURITY.md`.
- Criar ou revisar `docs/DEPLOYMENT.md`.
- Criar `.codex/project.md`.

## Fora De Escopo

- Implementar endpoints.
- Criar deploy real.

## Critérios De Aceite

- Docs explicam comandos, arquitetura, ambientes, segurança e deploy planejado.
- `.codex/project.md` resume projeto, comandos e preferências de trabalho.
- Nenhum secret real aparece nos docs.
