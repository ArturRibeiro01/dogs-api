# GitHub Issues Locais

Esta pasta guarda o backlog inicial em Markdown antes de publicar as issues no GitHub.

Cada arquivo de issue segue a estrutura:

```md
## Contexto

## Objetivo

## Escopo

## Fora De Escopo

## Critérios De Aceite
```

Use `PRIORITY.md` para ver a ordem recomendada.

Quando uma issue for concluída:

- atualizar `docs/PROJECT_STATUS.md`;
- atualizar este README se a lista mudar;
- atualizar `PRIORITY.md`;
- opcionalmente remover o arquivo da issue se a equipe quiser manter só pendências.
