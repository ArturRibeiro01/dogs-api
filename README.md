# Dogs API

Backend próprio do Dogs, criado para substituir gradualmente a API pública usada pelo frontend `react-dogs`.

## Stack Inicial

- Node.js
- TypeScript
- NestJS
- Yarn

## Requisitos

- Node.js 18+
- Yarn 1.x

## Setup Local

Instale as dependências:

```sh
yarn install
```

Suba a API em modo desenvolvimento:

```sh
yarn dev
```

Por padrão a aplicação sobe em:

```txt
http://localhost:3333
```

## Scripts

```sh
yarn dev
yarn build
yarn start
```
